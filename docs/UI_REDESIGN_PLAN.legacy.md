# UI 重构设计方案

## 1. 现状分析

### bilibili-downloader
- **当前框架**: tkinter（原生）
- **优点**: 已有较完善的结构（导航栏、卡片、主题系统、设计令牌）
- **问题**:
  - tkinter 原生组件外观过时（直角、无阴影、无动画）
  - 按钮和输入框缺乏现代感
  - 主题切换未实际应用
  - 没有真正的圆角和层次感
  - 交互动效缺失

### TikTokDownload
- **当前框架**: 纯命令行（CLI）
- **问题**: 无GUI界面，对普通用户不友好

## 2. 重构目标

1. **简洁现代**: 采用扁平化设计 + 微妙的毛玻璃/阴影效果
2. **统一视觉**: 两个项目使用一致的设计语言
3. **明暗主题**: 支持系统级主题切换
4. **交互动效**: 按钮悬停、页面切换、加载状态等微交互动画
5. **响应式布局**: 自适应窗口大小变化
6. **视觉层次**: 通过卡片、阴影、间距建立清晰的信息层级

## 5. 交互动效规范

### 5.1 按钮悬停
- 背景色渐变过渡: 200ms ease-out
- 轻微上浮: translateY(-1px)
- 阴影增强

### 5.2 卡片悬停
- 阴影从 SM 变为 MD: 200ms ease
- 边框颜色轻微变化

### 5.3 页面切换
- 淡入淡出: 150ms ease-in-out
- 内容区域轻微位移: translateX(10px) -> 0

### 5.4 进度条
- 宽度变化平滑过渡
- 完成时颜色从 Primary 变为 Success

### 5.5 Toast 通知
- 从右侧滑入: 300ms ease-out
- 停留 5 秒后淡出: 200ms ease-in

## 6. 响应式设计

- 最小窗口尺寸: 860x680
- 默认尺寸: 1100x800
- 侧边栏: 固定 220px，小屏幕可折叠
- 内容区: 弹性布局，卡片自动换行
- 视频选择器网格: 根据宽度自适应列数 (2-4列)

## 7. 技术选型

### 7.1 主框架: customtkinter
- 基于 tkinter 的现代化封装
- 支持圆角、主题、动画
- 与现有代码兼容性好
- 跨平台支持

### 7.2 图标: 系统 Emoji + 自定义 SVG
- 使用 Segoe UI Emoji 或 Apple Color Emoji
- 关键图标使用 SVG 渲染

### 7.3 图片处理: Pillow
- 缩略图生成和缓存
- 封面图片加载

## 8. 组件清单

### 8.1 基础组件
- `CTkButton` - 主按钮、次级按钮、文字按钮
- `CTkEntry` - 单行输入
- `CTkTextbox` - 多行文本（URL输入、日志）
- `CTkSwitch` - 开关（高级选项）
- `CTkRadioButton` - 单选（画质、命名）
- `CTkCheckBox` - 多选（高级选项）
- `CTkSlider` - 滑块（重试次数）
- `CTkOptionMenu` - 下拉菜单
- `CTkSegmentedButton` - 分段按钮（筛选）

### 8.2 复合组件
- `Card` - 卡片容器
- `NavItem` - 导航项
- `ProgressCard` - 进度卡片
- `LogViewer` - 日志查看器
- `VideoGrid` - 视频网格
- `VideoCard` - 视频卡片
- `Toast` - 通知
- `ThemeToggle` - 主题切换
